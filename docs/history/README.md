# Historical Engineering Records

This directory preserves pre-product engineering evidence that remains useful for auditability but should not be presented as the current SimplixPay product/release history.

## H12 engineering changelog

[`H12-ENGINEERING-CHANGELOG.md`](H12-ENGINEERING-CHANGELOG.md) is a byte-for-byte archival copy of the large changelog that existed in the independently verified H12 source baseline before the standalone SimplixPay product repository was established.

It records detailed hardening corrections, harness work and historical engineering milestones. It is retained for provenance and technical review.

The canonical product-facing changelog is [`../../CHANGELOG.md`](../../CHANGELOG.md).

Do not rewrite archived evidence merely to align it with later naming or status terminology. Add clarifying context outside the archived file instead.
